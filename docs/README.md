## 🚀 快速开始（新成员必读）

### Step 1: 配置开发环境
```bash
# 1. 克隆项目
git clone https://github.com/Luckydajiupro/wealth-butler.git
cd wealth-butler

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置环境变量（复制模板）
cp .env.example .env
# 编辑 .env 填入数据库连接信息
```

### Step 2: 阅读核心文档（按顺序）
1. **[AI编码助手使用指南.md](./AI编码助手使用指南.md)** ← 最重要！确保你的AI工具遵守规范
2. **[开发计划.md](./开发计划.md)** ← 找到自己的任务清单
3. **[架构设计文档.md](./架构设计文档.md)** ← 理解系统架构

### Step 3: 开始开发
```bash
# 查看自己负责的模块（以投顾助手Agent为例）
cd app/WealthButler/Agent
# 参考 Base/ 脚手架的 baseAgent.py
```

## ⚠️ 重要提醒

### 给使用AI编码助手的团队成员

如果你使用**Cursor、GitHub Copilot、通义灵码**等AI工具开发：

1. ✅ **必须**在每次开发前将 [AI编码助手使用指南.md](./AI编码助手使用指南.md) 提供给AI
2. ✅ **必须**告诉AI："在本项目中必须严格遵守以上规范"
3. ✅ **必须**检查AI生成的代码是否符合规范（复用Base层、文件落点正确、无新框架）

**为什么要这样做？**
- 本项目在 `.claude/skills/` 配置了12个skill，但只有Claude Code能自动读取
- 其他AI工具看不到这些skill，需要你**手动提供规范**
- 否则AI可能生成不符合项目架构的代码（引入新框架、文件放错目录等）
