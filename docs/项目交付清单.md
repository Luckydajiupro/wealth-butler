# 智能财富管家系统 - 项目交付清单

## 1. 项目概述

### 1.1 项目信息
- **项目名称**：智能财富管家系统（Intelligent Wealth Butler System）
- **项目代号**：WealthButler
- **开发周期**：4天（Vibe Coding模式）
- **开发模式**：复用Base脚手架 + 快速迭代
- **代码行数**：约8000行（不含脚手架）
- **提交时间**：2026-08-16

### 1.2 技术选型
- **后端框架**：FastAPI + Uvicorn
- **AI框架**：LangChain + LangGraph
- **数据库**：MySQL + Redis + Milvus + Neo4j
- **LLM**：通义千问 + Ollama（bge-m3）+ DeepSeek
- **前端**：原生HTML/CSS/JS
- **部署方式**：Python虚拟环境 / Docker

## 4. 数据库表结构

### 4.1 用户相关（2张表）
- `base_user` - 用户表（客户 + 员工）
  - 字段：id, username, email, phone, password_hash, user_type, customer_level, extra_data
  - 索引：username, email, phone, user_type
  
- `fin_customer_profile` - 客户画像表
  - 字段：customer_id, risk_level, risk_score, dimension1-4_score, fm_flags, asset_allocation, product_preference, memory_units
  - 索引：customer_id, risk_level

### 4.2 产品交易（3张表）
- `fin_product` - 产品表
  - 字段：id, product_code, product_name, product_type, risk_level, min_investment, nav, status
  - 索引：product_code, risk_level, status

- `fin_transaction` - 交易流水表
  - 字段：id, customer_id, product_id, transaction_type, amount, shares, nav, fee, status, transaction_time
  - 索引：customer_id, product_id, transaction_type, status, transaction_time

- `fin_holdings` - 持仓表
  - 字段：customer_id, product_id, shares, cost_amount, current_value, profit_loss, profit_ratio
  - 索引：customer_id, product_id

### 4.3 风险管理（2张表）
- `fin_risk_alert` - 风险预警表
  - 字段：id, rule_id, rule_name, customer_id, severity, status, confidence, need_override, trigger_details, handle_result
  - 索引：rule_id, customer_id, severity, status, need_override

- `fin_risk_assessment` - 风险评估表
  - 字段：id, customer_id, assessment_type, result, score, risk_level
  - 索引：customer_id, assessment_type

### 4.4 业务工单（1张表）
- `biz_work_order` - 业务工单表
  - 字段：id, order_no, order_type, customer_id, customer_name, intent_summary, status, priority, handled_by, handler_name
  - 索引：order_no, customer_id, order_type, status, handled_by

### 4.5 知识库（2张表）
- `fin_conversation_archive` - 会话归档表
  - 字段：id, session_id, agent_type, customer_id, messages, metadata
  - 索引：session_id, agent_type, customer_id

- `fin_knowledge_meta` - 知识库元数据表
  - 字段：id, source_file, doc_title, doc_type, chunk_count, embedding_model, vector_ids
  - 索引：source_file, doc_type
