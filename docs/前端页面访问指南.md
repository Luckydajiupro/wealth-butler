## 四、使用流程

### 4.1 数据分析工作台使用

1. **登录系统**
   - 访问 http://localhost:8010/chat/analyst
   - 如果未登录，会自动跳转到登录页
   - 使用业务管理员账号登录

2. **NL2SQL查询**
   - 在"智能数据分析"输入框中输入自然语言查询
   - 示例：
     - "本月新增客户数"
     - "交易金额最高的5个产品"
     - "风险预警数量趋势"
   - 点击"查询"按钮
   - 查看查询结果表格

3. **查看查询历史**
   - 页面右侧显示最近5条查询历史
   - 点击"重新执行"可复用历史查询

4. **风控预警裁决**
   - 页面中部显示"待人工裁决预警"
   - 查看高风险预警详情
   - 点击"批准放行"或"确认拦截"

### 4.2 风控工作台使用

1. **登录系统**
   - 访问 http://localhost:8010/chat/risk
   - 使用风控专员账号登录

2. **查看预警列表**
   - 页面自动加载待处理预警
   - 使用筛选按钮：全部/高风险/中风险/低风险

3. **处理预警**
   - 点击"查看详情"查看完整信息
   - 点击"标记处理中"开始处理
   - 点击"标记误报"将预警标记为误报（需二次确认）

4. **查看趋势图**
   - 页面上方显示本周风险预警趋势
   - 三条折线分别代表高/中/低风险

5. **查看统计数据**
   - 今日预警总数
   - 待处理预警
   - 误报率
   - 已上报数量

## 六、常见问题

### 6.1 页面提示 "Not Found"

**原因**：路由未注册或服务未启动

**解决方案**：
1. 检查服务是否启动：访问 http://localhost:8010/docs
2. 使用推荐的访问路径（`/chat/analyst` 而不是 `/admin_dashboard`）
3. 如果修改了路由配置，需要重启服务

### 6.2 API返回 401 "缺少认证信息"

**原因**：未登录或Token过期

**解决方案**：
1. 清除浏览器缓存和localStorage
2. 重新访问登录页面登录
3. 确认登录成功后 localStorage 中有 `access_token`

### 6.3 API返回 403 "您没有查看风险预警的权限"

**原因**：当前用户角色无权限

**解决方案**：
1. 检查使用的测试账号是否正确
2. 业务管理员访问 `/chat/analyst`
3. 风控专员访问 `/chat/risk`

### 6.4 查询结果显示 "暂无数据"

**原因**：
1. 数据库中确实无数据
2. NL2SQL生成的SQL查询无结果
3. API调用失败，使用了Mock数据

**解决方案**：
1. 检查浏览器Console是否有错误
2. 查看Network面板的API请求响应
3. 确认数据库中有测试数据

### 6.5 图表不显示

**原因**：Chart.js库加载失败

**解决方案**：
1. 检查网络连接（Chart.js使用CDN）
2. 打开浏览器Console查看错误信息
3. 考虑使用本地化的Chart.js文件

## 八、开发者工具使用

### 8.1 检查API请求

1. 打开浏览器开发者工具（F12）
2. 切换到"Network"面板
3. 执行查询操作
4. 查看API请求和响应：
   - Request Headers: 是否有 `Authorization: Bearer <token>`
   - Response: 返回的数据格式和内容
   - Status Code: 200表示成功，401/403表示权限问题

### 8.2 查看JavaScript错误

1. 打开浏览器开发者工具（F12）
2. 切换到"Console"面板
3. 查看是否有红色错误信息
4. 常见错误：
   - `Uncaught ReferenceError`: 函数未定义
   - `Failed to fetch`: 网络请求失败
   - `Unexpected token`: JSON解析错误

### 8.3 检查LocalStorage

1. 打开浏览器开发者工具（F12）
2. 切换到"Application" > "Local Storage"
3. 查看 `http://localhost:8010` 下的数据
4. 应包含：
   - `access_token`: JWT Token
   - `username`: 用户名
   - `user_id`: 用户ID
   - `query_history`: 查询历史（JSON数组）

## 九、性能优化建议

### 9.1 前端优化

1. **图表库本地化**
   - 将Chart.js下载到本地 `/static/js/` 目录
   - 修改 `<script src="https://cdn.jsdelivr.net/...">` 为本地路径

2. **减少Mock数据**
   - 生产环境移除Mock数据降级逻辑
   - 改为友好的错误提示

3. **缓存策略**
   - 统计数据可缓存5分钟（避免频繁请求）
   - 预警列表可设置30秒自动刷新

### 9.2 后端优化

1. **数据库查询优化**
   - 为常用查询字段添加索引
   - NL2SQL生成的SQL添加LIMIT限制

2. **API响应缓存**
   - 统计数据使用Redis缓存
   - 趋势数据按天缓存
