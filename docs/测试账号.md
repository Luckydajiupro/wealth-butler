## 2. 角色详细说明

### 2.1 客户（customer0001）

**用户类型**：CUSTOMER

**可访问页面**：
- 登录页：`/wealth/login`
- 客户工作台：`/wealth/customer/dashboard`

**可用功能**：
- 智能客服对话（`POST /api/chat/customer`）
- 查看自己的持仓（`GET /api/wealth/holdings`）
- 查看交易历史
- 会话历史查询

**典型操作场景**：
```bash
# 1. 登录获取Token
curl -X POST http://localhost:8010/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"customer0001","password":"123456"}'

# 2. 查询持仓
curl -X GET http://localhost:8010/api/wealth/holdings \
  -H "Authorization: Bearer <token>"

# 3. 智能客服对话
curl -X POST http://localhost:8010/api/chat/customer \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"message":"我想了解货币基金","user_id":1,"is_stream":false}'
```

**Mock数据**：
- customer0001-customer0150共150个客户账号
- 每个客户都有完整的画像、持仓、交易数据
- 风险等级：C1-C5均匀分布
- 客户等级：普通/金卡/白金/钻石/私行

### 2.2 理财顾问（advisor001）

**用户类型**：EMPLOYEE

**角色标识**：拥有 `product:recommend` 权限

**可访问页面**：
- 理财顾问工作台：`/wealth/advisor/dashboard`

**可用功能**：
- 投顾助手对话（`POST /api/chat/advisor`）
- 查看客户画像
- 产品推荐（基于风险匹配）
- 适当性匹配校验
- 处理产品相关工单

**核心权限**：
- `product:recommend` - 产品推荐
- `customer:view_profile` - 查看客户画像
- `data:nl2sql_query` - 数据查询

**典型操作场景**：
```bash
# 1. 登录
curl -X POST http://localhost:8010/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"advisor001","password":"123456"}'

# 2. 为客户推荐产品
curl -X POST http://localhost:8010/api/chat/advisor \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "message":"推荐适合这位客户的产品",
    "user_id":2,
    "customer_id":1,
    "is_stream":false
  }'

# 3. 查询工单（自动筛选产品相关工单）
curl -X GET "http://localhost:8010/api/wealth/workorder/list?order_type=客户转介" \
  -H "Authorization: Bearer <token>"
```

**业务场景**：
- 客户咨询产品，顾问使用投顾助手快速推荐
- 查看客户风险等级和资产配置
- 领取"申购/赎回/产品推荐"相关工单

### 2.3 客户经理（operator001）

**用户类型**：EMPLOYEE

**角色标识**：拥有 `customer:manage` 权限

**可访问页面**：
- 客户经理工作台：`/wealth/operator/dashboard`

**可用功能**：
- 业务操作对话（`POST /api/chat/operator`）
- 代客户办理业务（申购、赎回、转账）
- 更新客户信息
- 创建工单
- 处理客户转介工单

**核心权限**：
- `customer:manage` - 客户管理
- `transaction:create` - 创建交易
- `workorder:create` - 创建工单
- `data:nl2sql_query` - 数据查询

**典型操作场景**：
```bash
# 1. 代客户申购产品
curl -X POST http://localhost:8010/api/chat/operator \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "message":"帮客户申购XX货币基金5万元",
    "user_id":3,
    "customer_id":5,
    "is_stream":false
  }'

# 2. 二次确认（申购金额>1万需要确认）
curl -X POST http://localhost:8010/api/chat/operator/confirm \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "confirm_token":"token_abc123",
    "action":"confirm"
  }'

# 3. 创建工单
curl -X POST http://localhost:8010/api/wealth/workorder \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "order_type":"客户转介",
    "customer_id":5,
    "intent_summary":"客户需要转账10万元到指定账户",
    "priority":"普通"
  }'
```

**业务场景**：
- 客户来电要求办理业务，经理使用NL2API快速执行
- 高额交易需要二次确认
- 创建并处理"转账/信息更新"相关工单

### 2.4 风控专员（risk001）

**用户类型**：EMPLOYEE

**角色标识**：拥有 `risk:monitor` 和 `risk:suspicious_report` 权限

**可访问页面**：
- 风控专员工作台：`/wealth/risk/dashboard`

**可用功能**：
- 查看风险预警列表（`GET /api/wealth/risk/alerts`）
- 处理风险预警（`PUT /api/wealth/risk/alert/{id}/handle`）
- 标记误报
- 上报可疑交易
- 查看风险统计

**核心权限**：
- `risk:monitor` - 风险监测
- `risk:suspicious_report` - 可疑交易上报
- `risk:view_alerts` - 查看预警

**典型操作场景**：
```bash
# 1. 查询待处理的风险预警
curl -X GET "http://localhost:8010/api/wealth/risk/alerts?status=待处理" \
  -H "Authorization: Bearer <token>"

# 2. 领取预警并标记为处理中
curl -X PUT http://localhost:8010/api/wealth/risk/alert/1/handle \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "action":"process",
    "remark":"已核实客户身份，正在调查资金来源"
  }'

# 3. 确认风险或标记误报
curl -X PUT http://localhost:8010/api/wealth/risk/alert/1/handle \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "action":"confirm",
    "remark":"确认为可疑交易，已上报反洗钱中心"
  }'

# 4. 查看风险统计
curl -X GET http://localhost:8010/api/wealth/risk/stats \
  -H "Authorization: Bearer <token>"
```

**业务场景**：
- 每日查看新增风险预警
- 调查可疑交易，确认或标记误报
- 高风险预警需要管理员裁决

**预警状态流转**：
```
待处理 → (process) → 处理中 → (confirm/mark_false) → 已确认/误报
```

  -H "Authorization: Bearer <token>" \

  -H "Content-Type: application/json" \

### 2.6 系统管理员（admin001）

**用户类型**：EMPLOYEE

**角色标识**：is_admin=True，拥有全部权限

**可访问页面**：
- 系统管理员工作台：`/wealth/admin/dashboard`

**可用功能**：
- 查看所有工单（不受角色筛选限制）
- 查看所有风险预警

- 用户管理
- 系统配置

**核心权限**：
- 全部业务权限
- `risk:override` - 风险裁决
- `user:manage` - 用户管理
- `system:config` - 系统配置

**典型操作场景**：
```bash
# 1. 管理员批准放行高风险预警
curl -X PUT http://localhost:8010/api/wealth/risk/alert/5/handle \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "action":"override_approve",
    "remark":"经核实为正常业务，批准放行"

# 2. 管理员确认拦截
curl -X PUT http://localhost:8010/api/wealth/risk/alert/6/handle \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "action":"override_reject",
    "remark":"确认为可疑交易，执行拦截"
  }'

curl -X GET http://localhost:8010/api/wealth/workorder/list \
  -H "Authorization: Bearer <token>"
```

**业务场景**：
- 处理需要管理员裁决的高风险预警

## 5. 注意事项

### 5.1 密码安全
- 所有测试账号密码均为`123456`
- 生产环境请务必修改默认密码
- 建议启用密码复杂度策略

### 5.2 数据隔离
- 客户只能查看自己的数据
- 员工可查看所有客户数据（根据权限）
- JWT Token携带用户身份信息

### 5.3 权限校验
- 所有API都经过JWT认证
- RBAC权限模型自动校验
- 越权操作返回403错误

### 5.4 Mock数据重置
```bash
# 重新生成Mock数据
python scripts/generate_mock_data_v3.py

# 清空数据库重新导入
mysql -u root -p wealth_butler < scripts/mock_data_seed.sql
```
