## 八、实际可演示功能清单

### 8.1 完整业务闭环（5个场景）

#### 场景1：智能客服咨询
```
客户："货币基金的收益率是多少？"
  → CustomerServiceAgent
  → 意图分类：产品咨询
  → RAG检索产品知识库（Milvus向量检索）
  → 返回答案 + 来源引用
  → 会话归档MySQL
```

#### 场景2：投资顾问推荐
```
客户："帮我推荐适合的理财产品"
  → AdvisorAgent
  → 加载客户上下文（风评+画像+持仓）
  → 适当性过滤（C1-C5 vs R1-R5）
  → Neo4j图谱查询（NL2Cypher）
  → Milvus向量检索
  → GraphRAG融合排序（0.6:0.4）
  → 五因子排序
  → LLM生成推荐理由
  → 返回Top3产品 + 审计信息
```

#### 场景3：数据分析查询
```
分析师："统计上个月新增客户数量"
  → AnalystAgent
  → NL2SQL生成SQL语句
  → SQL安全校验（SELECT白名单）
  → 执行查询
  → 返回结果（新增523人）+ 执行耗时
```

#### 场景4：业务操作办理
```
客户："我要申购10万元基金"
  → OperatorAgent
  → IntentParser识别意图：purchase
  → 参数提取：product_id + amount
  → RBAC权限校验
  → 适当性校验（客户等级 vs 产品风险等级）
  → FM-02规则验证（R3仓位上限）
  → 二次确认判断（>1万触发）
  → 生成confirm_token
  → 返回确认提示
  → 客户确认后执行
```

#### 场景5：风控监测触发
```
系统：客户王五单日申购50万元
  → EventBus发布large_transaction事件
  → RiskAgent消费事件
  → 触发RW-001规则（单日交易超阈值）
  → 规则引擎评估（置信度计算）
  → 30天重复触发查询
  → 生成中风险预警
  → 创建工单分配给理财顾问
  → 发布risk_alert事件通知其他Agent
```
